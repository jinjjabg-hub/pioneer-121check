# 파이오니어 121 체크

BNI 파이오니어 챕터 멤버가 서로 어느 단계까지 121을 했는지(패스포트 → 아는 → 신뢰 → 수익) 스스로 체크하고, 구글시트로 모으는 페이지. 로그인 없이 쓴다.

- `index.html`: 체크 페이지(파일 하나로 동작). 맨 위 `SHEET_URL`에 아래 웹앱 주소를 넣는다.
- `apps-script.gs`: 구글시트에 붙이는 취합 스크립트.
- `firestore.rules`: 121 일정(Firebase Firestore, 프로젝트 `pioneer-121`)의 보안 규칙.

## 구글시트 만들기 (처음 한 번)
1. 새 구글시트 `파이오니어 121 체크` 생성 → 확장 프로그램 → Apps Script
2. 기존 코드를 지우고 `apps-script.gs` 내용을 붙여넣고 저장
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → 권한 허용
4. 나온 웹 앱 주소를 `index.html`의 `SHEET_URL`에 붙여넣기
5. 확인: `웹앱주소?me=테스트` 를 열어 `{"ans":{}}` 가 보이면 성공

시트에는 `체크`(나·상대·단계)가 쌓이고, 메뉴 `121 체크 → 매트릭스 만들기`로 멤버×멤버 표를 만든다.

## 멤버 바꾸기
`index.html`의 `MEMBERS` 목록(`n` 이름, `co` 회사, `f` 업종)을 고친다. 목록 순서가 화면 순서이며 **챕터 가입 순서**로 둔다(새 멤버는 맨 뒤에 추가).

## 주소로 열기
저장소 Settings → Pages → Branch `main` / `/ (root)` → Save.

## 121 일정 탭 (Firebase)
탭 순서는 **121 일정 → 121 체크**이고, 주소 끝이 없으면 121 일정이 먼저 열린다(`#check`를 붙이면 121 체크가 먼저).

멤버가 만날 수 있는 시간을 열고, 다른 멤버가 신청하면 확정된다. 확정되면 열린 목록에서 사라지고 두 사람 "내 일정"에 남는다. 같은 칸을 두 명이 동시에 눌러도 한 명만 확정된다(트랜잭션 + 보안 규칙).

- 위쪽 "내 이름"을 고른 뒤 **121 일정** 탭에서 방식(대면/온라인/둘 다)을 고르고 **격자 칸을 눌러 칠한다**(09:00~18:00, 30분 단위, 7일씩 4주). 같은 방식으로 다시 누르면 지워지고, 날짜·시간 이름을 누르면 한 줄이 칠해진다. 컴퓨터는 끌어서 여러 칸을 칠할 수 있다. "저장"을 눌러야 반영된다.
- 다른 멤버의 열린 시간은 "한눈에 보기"(요일×시간대, 열어 둔 멤버 수)에서 칸을 눌러 거르고, 아래 목록의 시간 버튼을 누르면 신청(확인 창 후 확정)된다.
- 선샤인(`pioneer-sunshine`)의 121 추천 카드 "121 일정 잡기 ↗"는 `?me=이름#sched`로 이 탭을 연다.
- 저장소는 구글시트가 아니라 Firebase Firestore다(121 체크 기록은 그대로 구글시트).
- **규칙 게시:** `firestore.rules`를 바꾸면 Firebase 콘솔 → Firestore Database → 규칙에 붙여 넣고 게시해야 적용된다.
- 한계: 본인 확인이 이름 선택뿐이라 남의 시간을 지울 수 있다.

## 로그인 (이름 + 전화번호 뒤 4자리)
앱을 열면 먼저 로그인한다. 이름을 고르고 전화번호 뒤 4자리를 넣으면 들어가고, **내 체크와 내 일정은 로그인한 본인만** 바꿀 수 있다(남의 이름으로 열기·신청·삭제가 서버에서 거부된다). 같은 기기에서는 다시 열어도 자동으로 로그인되어 있고, "로그아웃"을 누르면 풀린다.

- 한계: 4자리 번호는 멤버끼리 서로 알 수 있는 값이라 **실수·장난을 막는 수준**이다. 마음먹고 남인 척하는 것까지는 막지 못한다.
- **번호는 이 저장소에 올리지 않는다.** `firestore.rules`와 `apps-script.gs`의 `'____'` 자리는 자리표시이고, 실제 번호는 아래 두 곳(Firebase 콘솔, Apps Script 편집기)에만 넣는다.

### 처음 한 번 하는 설정
1. Firebase 콘솔 → Authentication → 시작하기 → Sign-in method → **익명** 사용 설정(로그인 기록을 만들 때 쓴다).
2. Firebase 콘솔 → Firestore Database → 규칙에 `firestore.rules`를 붙여 넣되 `'____'`를 각자의 번호로 바꿔 **게시**.
3. (체크 기록까지 보호) 구글시트 → Apps Script에 `apps-script.gs`를 붙여 넣되 `PINS`의 `'____'`를 번호로 바꾸고 → 배포 → 배포 관리 → **새 버전**으로 배포(웹앱 주소는 그대로).
4. 새 멤버가 들어오면 `index.html`의 `MEMBERS`, `firestore.rules`의 `pins()`, `apps-script.gs`의 `PINS`에 이름을 추가하고 두 곳을 다시 게시한다.
